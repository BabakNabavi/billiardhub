# ممیزی عملیات به عملیات

تعریف وضعیت‌ها:
- **PASS (ایستا)**: مسیر کد از رابط تا API تا نگهبان تا نوشتن دیتابیس خوانده و درست دیده شد؛ اجرا نشد.
- **PASS (زمان اجرا)**: واقعاً اجرا شد. این‌جا یعنی درخواست مستقیم بی‌نشست به سایت زنده، که باید رد شود (۴۰۱/۴۰۳).
- **FAIL ⟵ رفع شد**: نقص تأییدشده که در همین ممیزی اصلاح شد.
- **NOT VERIFIED**: بدون اجرای عملیات تغییردهنده قابل اثبات نبود. محیط آزمایشی جدا وجود ندارد و سرور محلی به همان دیتابیس زنده وصل است؛ اجرای واقعی یعنی تغییر داده‌ی واقعی، که این مأموریت ممنوع کرده.
