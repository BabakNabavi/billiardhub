# راهنمای استفاده از بسته استاندارد لوگوی HB

همه‌ی فایل‌ها از روی لوگوی اصلی شما، دقیقاً هم‌مرکز و با کیفیت بالا ساخته شده‌اند تا در همه‌جا یکسان و حرفه‌ای دیده شوند.

## فاوآیکون وب‌سایت
- **favicon.ico** → همین فایل را در ریشه‌ی سایت (`/favicon.ico`) قرار دهید؛ خودش سه‌سایز (16، 32، 48) را داخلش دارد.
- **favicon-16x16.png / favicon-32x32.png** → برای تگ‌های `<link rel="icon">` در HTML.
- **apple-touch-icon-180x180.png** → برای آیفون/آیپد، وقتی کاربر سایت را به صفحه‌ی اصلی اضافه می‌کند.
- **android-chrome-192x192.png / 512x512.png** → برای `site.webmanifest` و PWA اندروید.

نمونه کد داخل `<head>`:
```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon-180x180.png">
```

## لوگوی سایت (هدر/فوتر)
- **website-logo-512x512-transparent.png** و **website-logo-1024x1024-transparent.png** → پس‌زمینه شفاف، روی هر رنگ پس‌زمینه‌ای (روشن یا تیره) تمیز می‌نشیند.
- **website-logo-1000x1000-full.png** → نسخه‌ی کامل با حلقه‌ی دور و پس‌زمینه‌ی ملایم اصلی، مناسب استفاده به‌عنوان مهر/نشان مستقل.

## اینستاگرام
- **instagram-profile-1080x1080.png** → عکس پروفایل (اینستاگرام خودش آن را در قاب دایره نمایش می‌دهد، نیازی به برش دایره‌ای نیست).
- **instagram-post-1080x1080.png** → همان فایل، برای استفاده در پست/های‌لایت در صورت نیاز.

## واتس‌اپ
- **whatsapp-profile-640x640.png** → سایز پیشنهادی واتس‌اپ بیزینس برای عکس پروفایل.

## نکته فنی
تمام سایزها از یک فایل مرجع با کیفیت ۲۰۰۰×۲۰۰۰ پیکسل و مرکز دقیق یکسان تولید شده‌اند، بنابراین در هیچ‌کدام از پلتفرم‌ها لوگو کج، جابه‌جا یا برش‌خورده به نظر نمی‌رسد.
